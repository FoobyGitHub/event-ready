# Changelog

## [Unreleased] (alpha)

First version.

- Situations: Party and Raid group (open world), Dungeon, Raid, Battleground and Arena. Inside an instance the instance type decides; outside, the group size.
- For each situation, tick which names and nameplates to hide. Everything comes back as you had it when you are solo again. Changes wait until combat ends.
- Profiles shared across your account: use one on every character, or give a character its own. New, copy into mine, delete and reset.
- Settings in the game's Options > AddOns > Event Ready, with a Profiles page.
- `/evr` commands: on, off, status, profile, watch, help.
